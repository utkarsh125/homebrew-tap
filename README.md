# Homebrew Tap for Morrow

Official Homebrew tap for [Morrow](https://github.com/utkarsh125/morrow), a calm, keyboard-first terminal workspace for chatting with local LLMs.

## Installation

```bash
brew install utkarsh125/tap/morrow
```

Or add the tap first:

```bash
brew tap utkarsh125/tap
brew install morrow
```

## Documentation

See the main [Morrow Repository](https://github.com/utkarsh125/morrow) for usage, shortcuts, and themes.
